# =============================================================================
# JARVIS backend — container dependency set
# =============================================================================
# Mirrors backend/requirements.txt, with deltas noted below. Kept as a separate
# file because a few entries in the full list either cannot work inside a
# headless Linux container or duplicate a capability the image already has.
#
# Deliberately EXCLUDED (see README "Docker" section):
#   pyautogui, mss      — desktop control / screen capture; need an X display.
#                         FEATURE_COMPUTER_USE_ENABLED defaults to false anyway.
#   easyocr             — second OCR backend; pulls torch-vision + opencv +
#                         scikit-image (~2 GB). pytesseract is installed and the
#                         image ships tesseract-ocr.
#   chromadb            — not imported anywhere; Qdrant is the vector store.
#   openai-whisper      — local Whisper STT; pulls numba/llvmlite. Hosted STT
#                         (Groq Whisper / AssemblyAI / Deepgram) works as-is.
#   playwright          — the browser agent also needs `playwright install`
#                         (~1 GB of browsers); add both if you need that agent.
# =============================================================================
